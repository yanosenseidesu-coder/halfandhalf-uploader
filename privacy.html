プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-11-07

1. このツールについて / About

halfandhalf-uploader は、運営者本人が自分のYouTubeチャンネルに動画を投稿するためだけに使う個人用ツールです。
halfandhalf-uploader is used only by its owner to upload videos to the owner's own YouTube channels.

2. 利用するデータ / Data accessed

  • Googleアカウントでのログイン（OAuth）を通じて、YouTube Data API の権限（https://www.googleapis.com/auth/youtube）を使い、動画のアップロード、タイトル・説明・公開設定の登録、チャンネル名の確認を行います。
    Through Google OAuth, the tool uses the YouTube Data API scope (https://www.googleapis.com/auth/youtube) to upload videos, set their title, description and privacy/schedule, and read the channel name.

3. 保存と共有 / Storage and sharing

  • ログインの情報（アクセストークン・リフレッシュトークン）は運営者のコンピューター内にのみ保存され、外部のサーバーには送信・保存しません。
    OAuth tokens are stored only on the owner's computer and are not sent to or stored on any other server.
  • 取得したデータを第三者に販売・共有・広告に利用することはありません。
    No data is sold, shared with third parties, or used for advertising.

4. YouTube API サービス / YouTube API Services

このツールは YouTube API サービスを利用しています。利用にあたっては YouTube 利用規約 と Google プライバシーポリシー が適用されます。
This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see the Google Privacy Policy.

5. アクセスの取り消し / Revoking access

このツールへの許可は、いつでも Googleアカウントの「サードパーティによるアクセス」 から取り消せます。
Access can be revoked at any time at Google Account permissions.
